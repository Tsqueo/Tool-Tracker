TOOL TRACKER V5.1.0 — COMPLETE APP REBUILD

This ZIP upgrades the actual Tool Tracker app. It is not the standalone
Christmas preview. It has not been deployed to your live GitHub Pages site
or Firebase project.

INSTALL
1. Extract this ZIP. Keep a backup of the currently deployed app.
2. Firebase Console > Firestore Database > Rules: publish firestore.rules
   from this package. V5.1 adds a private per-user moraleWeeks collection so
   weekly Foreman, Measure Twice and fact progress can sync across devices.
   Storage rules are unchanged from V5.0.1.
3. Upload the extracted CONTENTS to the root of your existing Tool Tracker
   GitHub repository, alongside index.html. Include every folder, especially
   boss, winter, christmas-art and halloween-art. Commit the replacement.
4. Wait for GitHub Pages to finish its deployment. Open the app online,
   refresh, then close and reopen the installed app. Confirm V5.1.0 appears.
   Keep the first online load open while artwork is cached.

Do not import inventory, reset users, delete app data, or upload the ZIP into
Firebase Storage. Existing tools, requests, accounts and saved Boss attempts
are retained. Weekly content progress uses new per-user keys for this update;
old locally stored V5.0.1 content scores are not imported into new questions.

POST-INSTALL CHECK
Sign in, open inventory and an existing request. Solve a weekly challenge,
then open the same account on a second device and check its saved progress.
Open the Boss puzzle, start/pause/return, and confirm the same remaining clock.
Christmas scenes activate automatically from November 30 through January 9;
Christmas is not forced on outside its seasonal window.
